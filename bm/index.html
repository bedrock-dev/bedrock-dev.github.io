BedrockMap

Minecraft 基岩版世界编辑器

基于 Qt6 与 C++17 开发的开源地图编辑器，直接读写 LevelDB 存档，用来浏览、检查与编辑基岩版世界的每一个区块。

下载最新版查看源码

支持基岩版 1.2 ~ 1.21 存档 · 无需安装，解压即用

核心功能

  • 世界浏览

    打开并浏览主世界、下界、末地与自定义维度的全部区块数据。

  • 地形可视化

    生物群系地图与地形叠加渲染，渲染滤镜可自由配置。

  • 区块编辑器

    选中、查看与删除区块，并可视化区块内的实体、方块实体与计划刻。

  • 区块复制粘贴

    框选区域后复制到其他存档，支持交互式放置与位置微调。

  • NBT 编辑器

    查看与修改 NBT 数据，包括 level.dat、玩家背包、村庄、地图物品等其他数据。

  • mcstructure 支持

    以 3D 体素预览浏览编辑 .mcstructure，也可把选区或区块导出为 mcstructure 或 GLB 模型，或者将 mcstructure 文件导入世界

主要快捷键

打开世界后，把世界文件夹或存档文件拖进窗口即可开始。

鼠标操作

左键拖动平移地图
右键点击打开上下文菜单
中键拖动框选区域
滚轮缩放

键盘快捷键

Ctrl+O打开世界
Ctrl+Shift+O打开文件（.mcstructure / .nbt / .nbts）
Ctrl+C / Ctrl+V复制 / 粘贴选中区域（可跨世界）
Ctrl+E / Ctrl+I导出 / 导入选区
Ctrl+D删除选中区块
Ctrl+H打开 3D 体素视图
Ctrl+G跳转到指定坐标
Alt+1 ~ Alt+4切换维度（主世界 / 下界 / 末地 / 自定义）
