# 基本使用

## 下载与安装

从 [Releases 页面](https://github.com/bedrock-dev/BedrockMap/releases) 下载最新版本，解压后直接运行，无需安装。

系统要求：Windows 10 及以上。存档支持基岩版 1.2（以及可能更早）到 1.21 系列。

## 打开世界

三种方式任选：

1. **文件 → 打开**（`Ctrl+O`），选中世界文件夹（形如 `bedrock-server-xxx/worlds/xxx` 或客户端的存档目录）
2. 把**世界文件夹直接拖进窗口**
3. 在欢迎页的**最近存档**里点开，或者在 **文件 → 最近打开** 里挑

欢迎页会列出扫描到的世界，区分**正式版**和**预览版**；鼠标悬停可"打开文件夹位置"。

同一个窗口可以开多个世界，也可以拖入 `.mcstructure`、`.nbt`、`.nbts` 文件——文件类型见 [NBT 编辑器](/bm/guide/nbt)。

## 在地图上看世界

| 操作     | 说明           |
| -------- | -------------- |
| 左键拖动 | 平移地图       |
| 滚轮     | 缩放           |
| 右键     | 打开上下文菜单 |
| 中键拖动 | 框选区域       |
| `Ctrl+G` | 前往坐标       |

## 切换维度

| 快捷键  | 维度       |
| ------- | ---------- |
| `Alt+1` | 主世界     |
| `Alt+2` | 下界       |
| `Alt+3` | 末地       |
| `Alt+4` | 自定义维度 |

也可以用窗口工具栏上的按钮切换。自定义维度会弹出一个列表让你选，如果存档里没有自定义维度会提示"无自定义维度"。

## 切换图层

**图层**菜单（或工具栏）控制地图上叠了什么：

| 快捷键  | 图层                                     |
| ------- | ---------------------------------------- |
| `Alt+G` | 显示网格                                 |
| `Alt+C` | 显示坐标                                 |
| `Alt+T` | 地形                                     |
| `Alt+B` | 群系                                     |
| `Alt+S` | 史莱姆区块                               |
| `Alt+A` | 实体                                     |
| `Alt+V` | 村庄                                     |
| `Alt+H` | HSA（硬编码结构区域）                    |
| `Alt+0` | 透明虚空                                 |
| `Alt+O` | 坐标范围小窗                             |
| `Alt+F` | 过滤（按群系 / 方块 / 实体过滤显示内容） |

地形和群系是两种互斥的底图，其余图层可以叠加。渲染风格、阴影、实体图标样式等在 **工具 → 设置**（`Ctrl+,`）的"地图设置"里调。

## 保存

改完记得 **文件 → 保存**（`Ctrl+S`）。关闭有未保存修改的标签页会提示你，直接关掉窗口也会拦一次。
