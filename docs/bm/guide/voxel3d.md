# 3D 视图的数据导入导出

## 打开

三种方式：

- 选中区域后按 `Ctrl+H`
- **区块** 菜单 → **3D视图**
- 地图上右键 → **3D视图**

## 视图操作

| 操作               | 说明        |
| ------------------ | ----------- |
| 左键拖动           | 旋转视角    |
| 右键拖动           | 平移        |
| `Shift` + 右键拖动 | 沿 Z 轴平移 |
| 滚轮               | 缩放        |
| 中键拖动控制点     | 调整选区    |
| 方向键             | 旋转 90°    |

功能键：

| 按键 | 说明                   |
| ---- | ---------------------- |
| `R`  | 重置视图               |
| `F`  | 正视当前最接近屏幕的面 |
| `O`  | 切换正交投影           |
| `A`  | 切换坐标轴             |
| `L`  | 锁定左键旋转           |
| `S`  | 切换选区启用           |
| `M`  | 切换移动模式           |

侧栏的**选区**里能看到**最小 / 最大**坐标（与游戏内世界坐标一致，最大边界不包含在内）。开启**移动模式**后，中键拖动控制点可以整体平移选区而不改变大小。

## 导出

导出面板上：

| 项         | 说明                                                |
| ---------- | --------------------------------------------------- |
| 导出       | 存为 `.mcstructure` 结构文件                        |
| 导出 GLB   | 存为 glTF 二进制（`.glb`），可以拿去 Blender 等软件 |
| 压缩       | 压缩导出的结构                                      |
| 导出实体   | 连同实体一起导出                                    |
| 使用新格式 | 新版 mcstructure 格式，仅适用于版本 ≥ 26.50.24      |

导出前确认选区范围：范围里没有可见的体素面时会直接报错。

## 导入

点**导入**选择 `.mcstructure` 文件后会提示"进入放置模式，拖动选框选择导入位置"：

1. 拖动选框把模型放到目标位置
2. **确认** 完成导入，或 **取消** 退出

如果选到的不是有效结构文件会提示"不是有效的 mcstructure 文件"。

导入导出的都是结构数据，和 [区块操作](/bm/guide/chunks) 里的选区复制粘贴不是同一套剪贴板。
