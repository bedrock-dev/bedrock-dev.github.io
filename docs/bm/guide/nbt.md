# NBT 编辑器

## 打开 NBT 文件

**文件 → 打开文件**（`Ctrl+Shift+O`），或者直接把文件拖进窗口。支持的类型：

```
Minecraft 数据文件 (*.mcstructure *.nbt *.nbts *.palette)
```

`.mcstructure` 会以结构页打开，`.nbt` / `.nbts` 走 NBT 编辑器。

## 新建 NBT 文件

**文件 → 新建 → NBT 文件**（`Ctrl+N`），得到一个空白的 NBT 树，编辑完用**保存**（`Ctrl+S`）或**另存为**写到磁盘。

编辑器顶部还有：

- **加载** —— 往当前编辑器里换个文件读
- **多选** —— 一次操作多个节点
- **16 进制** —— 切到十六进制视图，直接看原始字节
- **打印缓存** —— 输出缓存内容，排查解析问题时用

## 编辑节点

在树上右键节点：

| 菜单项          | 说明                             |
| --------------- | -------------------------------- |
| 新建            | 加子节点，弹窗填类型 / 名称 / 值 |
| 修改            | 改选中节点的类型、名称或值       |
| 删除 / 删除选中 | 删掉节点，根节点不能删           |
| 清空            | 清空全部内容，会二次确认         |
| 导出选中        | 把选中节点单独导出               |
| 取消全选        | 取消多选                         |

弹窗里三个字段：**类型**（TAG 类型）、**名称**、**值**。名称不能为空，类型要合法，值不能为空——填错会分别提示。数据损坏或解析失败时会直接报"无法解析"。

## 直接改存档里的 NBT

不用把 NBT 单独导出来，存档内的数据可以直接编辑：

- **工具 → 全局NBT** —— 编辑 `level.dat` 这一层的数据
- **区块编辑器** 里的**实体 / 方块实体 / 计划刻** —— 点开就是对应的 NBT，见 [区块编辑器](/bm/guide/chunk-editor)
- **统计数据** 列表里每条数据都能**查看**，也能单独**导出**

改完同样要 `Ctrl+S` 才落盘。

:::warning
NBT 是存档的真实数据，改错会直接影响存档。动手前先复制一份存档目录。
:::
