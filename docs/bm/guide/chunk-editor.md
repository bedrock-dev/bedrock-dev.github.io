# 区块编辑器

## 打开

在地图上**右键 → 在区块编辑器中打开**。

## 顶部按钮

| 按钮    | 作用                                                |
| ------- | --------------------------------------------------- |
| 3D 视图 | 当前区块进体素预览，见 [3D 视图](/bm/guide/voxel3d) |
| 导出    | 把区块数据导出成文件                                |
| 导入    | 从文件导入区块数据                                  |
| 定位    | 定位到对应位置                                      |
| 关闭    | 退出区块编辑器                                      |

## 看什么

左侧的开关决定渲染出哪些内容：

- **地形**、**显示网格**
- **图层** / **高度 Y** —— 按 Y 高度切层查看，是查地形和建筑断层的主要方式
- **实体**、**方块实体**、**计划刻** —— 分别把三类数据标出来
- **HSA 区域** —— 硬编码结构刷怪区域

## 查看与编辑数据

打开**统计数据**，会列出当前区块的数据条目，字段为 **名称 / 大小 / 哈希 / 操作**：

- **查看** —— 打开该条数据的 NBT 编辑器
- **导出** —— 把这条数据单独存成文件

实体、方块实体、计划刻的数据都能这样点开改，改法见 [NBT 编辑器](/bm/guide/nbt)。

数据太大时不会硬开，而是提示"数据过大无法打开"，并在那里提供**删除数据**。

改完点 **保存区块数据** 写回。多选、删除这类批量操作也在同一套界面里。
