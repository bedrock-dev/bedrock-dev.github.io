# 区块操作

## 框选区域

在地图上**按住中键拖动**即可框选。选区模式决定新框选的内容怎么和已有选区合并：

| 快捷键    | 模式     | 说明                         |
| --------- | -------- | ---------------------------- |
| `Shift+R` | 添加选区 | 用新框选替换现有选区         |
| `Shift+A` | 增量添加 | 把新框选并进现有选区         |
| `Shift+S` | 删除选区 | 从现有选区里挖掉新框选的部分 |
| `Shift+C` | 清空选区 | 扔掉全部选区                 |

这些也在 **选区** 菜单里。

## 复制与粘贴

| 快捷键   | 操作               |
| -------- | ------------------ |
| `Ctrl+C` | 复制选区           |
| `Ctrl+V` | 粘贴到当前视角位置 |

复制粘贴**按维度分开存放**：在主世界复制的内容，切到下界粘贴进去的是下界的那份剪贴板。跨存档粘贴也没问题——复制后打开另一个世界直接粘贴即可。

剪贴板是空的或者数据对不上时，会提示"剪贴板中没有可粘贴的区块数据""剪贴板数据不合法，无法解析"。

## 导入与导出

| 快捷键   | 操作                       |
| -------- | -------------------------- |
| `Ctrl+E` | 导出选区到文件（`.bchks`） |
| `Ctrl+I` | 从文件导入选区             |

导出的是**选区文件**，和 [3D 视图里导出 mcstructure](/bm/guide/voxel3d) 是两套东西：前者用于在同一套工具里搬运区域，后者用于结构方块。

## 删除、虚空与群系

| 快捷键   | 操作     | 说明                                     |
| -------- | -------- | ---------------------------------------- |
| `Ctrl+D` | 删除选区 | 删掉选区内的区块，下次加载按种子重新生成 |
| `Ctrl+K` | 创建虚空 | 把选区内容清空成虚空                     |
| `Ctrl+B` | 修改群系 | 弹出群系选择器，改选区的群系             |
| `Ctrl+T` | 选区截图 | 把选区渲染成图片保存                     |

## 右键菜单

在地图上右键，能拿到和当前坐标、选区相关的一堆东西：

- **在区块编辑器中打开** —— 进入单区块视角，见 [区块编辑器](/bm/guide/chunk-editor)
- **3D 视图** —— 进入体素预览，见 [3D 视图](/bm/guide/voxel3d)
- **导出 mcstructure** —— 直接把选区存成结构文件
- **前往坐标**、**选区截图**、**取消选择**
- **复制信息** —— 方块名字 / 群系名字 / 高度信息 / TP 命令

改动都在内存里，**文件 → 保存**（`Ctrl+S`）之后才写回存档。
